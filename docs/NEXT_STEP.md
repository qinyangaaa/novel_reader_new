# NEXT_STEP.md

当前阶段：

`MVP Readable State`

当前主应用已具备：

- 书架
- 搜索
- 阅读页
- 阅读进度恢复
- 章节预加载
- 基础错误处理

## 下一批任务

1. 优化 `SearchScreen`

- 搜索结果布局更清晰
- 加入更稳定的加载中状态
- 降低搜索失败后的空白感

2. 优化 `ReaderScreen`

- 增加目录入口或章节列表入口
- 优化翻页后的状态提示
- 继续收敛长文本渲染性能

3. 优化本地章节体验

- 更好地区分已下载 / 未下载章节
- 改善预加载命中率
- 减少重复抓取边界情况

4. 真机验证

- Android 上的滚动与字体缩放体验
- 后台切前台后的阅读页恢复
- 预加载任务在真机环境下的稳定性

## 暂不做

- 新 runtime 层
- 新 manager
- 重构 EventBus
- 修改 lifecycle 架构
- Notification system
- 正式后台服务

## 进入下一阶段的标志

当以下项基本稳定后，可进入更完整的 UI / Reader 体验阶段：

- 搜索到阅读链路稳定
- 阅读进度恢复稳定
- 章节预加载稳定
- 基础错误处理可用
- Android 真机可完成一次完整阅读流程
